改动计划 · 自选股功能

项目：A股云图 本地优化版（D:\autoagent_file\a-share-heatmap）｜当前版本 v16｜2026-08-06
范围：纯前端本地功能，无后端、无新增数据源，与 8 秒实时 + 区间涨跌幅（v13-v16）完全兼容。

一、需求

1. 把关心的个股加入「自选股」，随时查看实时行情；
2. 本地存储（localStorage），刷新 / 重启浏览器不丢失；
3. 与现有 8 秒实时刷新、区间涨跌幅切换联动；
4. 操作路径短：悬停个股 → 一键加自选；面板点击个股 → 跳雪球。

二、功能设计

1. 添加 / 移除自选（入口）

主入口（一期）：二级页（个股网格）悬停任意股票 → 现有 tooltip 浮层底部新增按钮：
  • 未自选：☆ 加自选（点击后变为 ★ 已自选）
  • 已自选：★ 移出自选
防重复：重复添加自动忽略；按钮状态实时反映。
备选入口（二期）：首页搜索框下拉结果直接加星标。

2. 自选面板（右侧悬浮抽屉）

• header 新增按钮 ★ 自选 (N)，点击展开 / 收起 280px 宽悬浮面板（绝对定位覆盖画布右侧，不挤压热力图）；
• 每行：名称 + 代码 + 现价 + 所选区间涨跌幅（主，与主界面区间联动、红涨绿跌）+ 当日涨跌幅（小字对照）+ 行尾 × 删除；
• 点击行 → 跳雪球个股页（复用现有 xueqiuSymbol()）；
• 面板底部：清空自选；空状态提示：「还没有自选股，去个股页悬停格子点 ☆ 添加」；
• 有自选时按钮高亮（金黄色），数量实时更新。

3. 数据与实时联动

• 存储：localStorage heatmap_watchlist = JSON 数组 [{code, name, secid, ts}]（ts 添加时间，默认按添加顺序）；
• 初始行情：data.json 快照秒出（自选股均在全量 5545 只内，按 code 索引）；
• 盘中实时：8 秒刷新把自选 secid 并入现有 fetchQuotesBatch 批次（单批 500 上限，几十只零压力），返回后增量更新面板行（现价 / 当日涨跌幅 / 区间字段）；
• 非交易时段：显示快照值 + 面板标注「收盘快照」；
• 区间联动：切换区间下拉框 → 面板每行主涨跌幅跟随切换（复用 rangePctOf 逻辑）。

4. 与现有功能融合（不破坏项）

✔ 指数栏、搜索、下钻、双击雪球、8 秒实时、区间切换全部不动；
✔ canvas 绘制主流程零侵入（面板与按钮为独立 DOM）；
✔ tooltip 是独立 HTML div（非 canvas 内），按钮点击天然与 canvas 事件隔离。

五、风险与对策

风险影响对策
localStorage 被浏览器清理自选丢失可接受；二期加「导出 JSON / 剪贴板」备份
tooltip 按钮点击冒泡到 canvas误触发下钻tooltip 为独立 DOM 覆盖层，点击不穿透；实施时先实测验证
自选股停牌行情无更新沿用现有「-」保留旧值逻辑
自选过多面板冗长、单批超限上限 200 只（超出提示）；200 只远低于 500 单批上限
与 8 秒刷新冲突面板价格回跳沿用 60s 结构刷新合并实时价格的既有机制
