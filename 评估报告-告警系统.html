评估报告 · 股价告警系统

项目：a-share-heatmap ｜ 日期：2026-08-10 ｜ 状态：可行性高，建议实施需提供企业微信 webhook key

一、需求理解

  • 告警条件：指定股票，设置价格阈值（如 ≥1700）或涨跌幅阈值（如当日 ≥5%、区间 ≥8%）
  • 触发推送：条件满足时，把告警信息发送到企业微信群（手机微信即时收到）
  • 与现有系统关系：数据沿用东财无鉴权接口（符合数据源纪律）；告警引擎放本地 server.py，浏览器关闭也不影响触发

二、现状盘点（可复用资产）

数据通道东财 push2 ulist 无鉴权接口，交易时段每 8 秒刷新，前端已验证可用
后端扩展点server.py 已有 /api/notes 读写 JSON 先例（do_GET/do_POST + 原子写），告警规则文件可完全复用此模式
前端 UI 模式自选面板（wlPanel）结构可参照做告警管理面板；controls 区可加入口按钮
行情节点数据st.price / st.pct / st.pct5 / st.pct10 / st.pct20 / st.pct60 / st.pctYTD 均已就位

三、可行性结论

结论：完全可行，推荐实施。

企业微信群机器人（webhook）是免费、无需企业应用审批、配置成本最低的推送通道——在群里添加一个自定义机器人即可拿到 webhook 地址，用 HTTP POST 发一条 JSON 就能推到群（手机微信同步提醒）。叠加本地 server.py 常驻运行的优势，告警引擎放在后端，浏览器关不关都不影响触发。

主要成本：server.py 增加告警引擎（轮询 + 规则状态机 + webhook 发送，约 120~150 行）+ 前端管理面板（约 120 行）。一次实施，两期拆做亦可。

四、方案设计

4.1 架构

┌──────────────┐ GET/POST ┌─────────────────────────────┐ │ 前端告警面板 │ ────────────► │ server.py /api/alerts │ │ (app.js) │ │ ├ 规则 CRUD → alerts.json │ └──────────────┘ │ └ webhook 配置 → webhook.json│ └──────────────┬──────────────┘ │ 后台轮询线程（8s） ▼ ┌─────────────────────────────┐ │ 东财 push2 ulist（无鉴权） │ │ → 规则状态机（去重/回滞） │ └──────────────┬──────────────┘ │ 条件满足 ▼ ┌─────────────────────────────┐ │ 企业微信群机器人 webhook │ │ POST qyapi.weixin.qq.com │ └─────────────────────────────┘

4.2 告警规则格式（alerts.json，前端可视化编辑）

{
  "600519": [
    {
      "id": "a1",
      "type": "price",      // price 现价 | pct 当日涨跌幅 | pct5 | pct10 | pct20 | pct60 | pctYTD
      "op": ">=",          // >= 或 <=
      "value": 1700,        // 阈值
      "note": "茅台站上1700提醒",
      "enabled": true,      // 启停开关
      "state": "idle",      // idle 待触发 | fired 已触发(等待回落复位)
      "firedAt": null,      // 最近触发时间
      "resetPct": 0.5       // 回落 0.5% 后复位（防抖动）
    }
  ]
}

4.3 触发与防重复（关键设计）

  • 回滞复位（推荐）：如「价格 ≥1700」触发后进入 fired 状态，需价格回落到 1700 × (1 − 0.5%) 才复位可再次触发——避免价格在阈值附近反复横跳造成刷屏
  • 冷却兜底：同一规则触发后 5 分钟内不重复推送（即使复位异常）
  • 手动重置：面板上可一键「重置已触发」；一次性提醒类规则可勾选「触发后自动停用」
  • 非交易时段：价格不跳动则不触发；开盘瞬间的跳空按新价格正常判定

4.4 推送内容模板（text 类型）

【股价告警】贵州茅台(600519)
现价：1702.00　+1.85%
触发条件：现价 ≥ 1700.00
备注：茅台站上1700提醒
时间：2026-08-10 14:32:05
可选 markdown 类型（彩色高亮）；支持 @所有人（每 20 分钟限一次，默认关闭）。企业微信群机器人限制：20 条/分钟、单条 ≤2048 字符，本场景远达不到上限。

五、交互流程

  1. 一次性配置：用户在企业微信群 → 设置 → 群机器人 → 添加自定义机器人 → 复制 webhook 地址 → 填入系统（前端设置入口，存 webhook.json，仅本机）
  2. 添加告警：热力图悬停股票 → 悬浮窗「＋告警」按钮（或自选面板/搜索）→ 弹窗选择类型（价格/涨跌幅）、方向（≥/≤）、填阈值 → 保存
  3. 运行：server.py 后台每 8 秒拉一次行情 → 规则状态机判定 → 触发即推送到群
  4. 管理：告警面板列表展示全部规则（状态/最近触发时间），可启停、编辑、删除、重置

七、风险与限制

风险级别说明 / 对策
webhook key 泄露中key 只存本机 webhook.json（不入库不进代码仓库）；任何人拿到 key 可往群里发消息——群机器人无鉴权是平台机制，务必仅本机保存
重复推送刷屏中回滞复位 + 冷却兜底 + 自动停用选项，三重防抖
服务未运行中告警依赖 start.bat 的 server.py 常驻；可建议开机自启（可选后续项）
网络/接口波动低抓取失败静默跳过不误报；推送失败重试 2 次
非交易时段无触发低价格静止属正常；如需开盘跳空提醒，开盘首轮数据即可判定
频率限制低群机器人 20 条/分钟，去重后实际远低于上限
