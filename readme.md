# A股云图 · 本地优化版

本地运行的 A 股全市场热力图（Treemap），自绘 canvas 渲染，解决 52etf.site 等在线工具的两个痛点：

1. **缩放无上限** —— 滚轮可放大到任意级别（等效无限），小市值公司的方块放大后足够大，公司名一定能显示；
2. **小方块标签自适应** —— 字号随方块大小自动缩放；悬停时无论方块多小都强制显示名称（放不下显示代码）。
3. ![](https://github.com/justycg5/stock-map/blob/main/%E4%BA%91%E5%9B%BE.PNG?raw=true)

## 功能

- 全市场 A 股（沪主板 / 深主板 / 创业板 / 科创板）按行业分组的热力图
- 红涨绿跌，方块面积 = 总市值权重，颜色深浅 = 涨跌幅（行业层为市值加权涨跌）
- 滚轮缩放（无上限）、拖拽平移、单击下钻行业、双击/面包屑返回
- 悬停详情：现价、涨跌幅、涨跌额、成交额、总市值、所属行业
- 搜索定位：输入股票名称 / 代码 / **行业名**（如「半导体」），股票自动下钻高亮，行业直接定位块并高亮闪烁；`/` 键聚焦搜索框，`Esc` 退出
- 手动刷新 + 自动刷新（默认 60s 重载本地数据）
- 停牌/无数据股票显示为灰色

## 使用

```bash
# 1. 抓取数据（首次必须执行；东方财富公开接口，免费）
python fetch_data.py            # 全量抓取
    python fetch_data.py --incremental  # 增量刷新（只更新价格，更快）

# 2. 启动本地服务
python -m http.server 8080 --directory .

# 3. 打开浏览器
#    http://127.0.0.1:8080
```

> 直接双击 index.html 打开无法加载 data.json（浏览器限制本地 fetch），必须通过 http.server 访问。

交易时段建议每 5 分钟更新一次行情（避免请求过频触发风控）：

```bash
# Windows 任务计划程序 / Linux crontab 均可，示例（每 5 分钟）：
*/5 * * * * cd /path/to/a-share-heatmap && python fetch_data.py --quiet
```

前端自动刷新（60s）会重载最新的 data.json，无需刷新页面。

## 自选跨端同步（v81）

- **问题**：电脑端添加自选，移动端看不到；反之亦然。根因：自选是"本地优先"存储——wlLoad 只在 localStorage 为空时才从服务端恢复，两端各自用本地数据，服务端 watchlist.json 仅作兜底备份，从不对账。
- **方案**：每次页面加载都拉取服务端，与本地按 ts 合并（ts 较新者胜），合并有变化时回写双方。
  - 新增合并：服务端有本地无 → 加入；本地有服务端无且服务端未被改写 → 保留本地（防误删）；服务端自上次本机同步后改写过 → 以服务端为准（删除生效）
  - 删除判定：GET /api/watchlist 新增 updated_ms（文件 mtime 毫秒），本机记录 wlLastSyncMs（POST 成功时更新）
  - 幂等：changed 深比较（code/name/ts），无差异不回写，避免每次加载都重写文件
- **服务端**：GET /api/watchlist 返回 updated_ms 字段
- 验证：CDP 10/10（mock）+ 真实端到端冒烟通过；用户测试时新增的 601288/603629/002850/603259 均在服务端，两端刷新后一致

## 应用模式启动（方案A，v69）

start.bat 已改为「网页应用」式启动：优先用 Edge 的 `--app` 独立窗口打开（无地址栏/标签栏，像桌面 App），Chrome 兜底，找不到则回退系统默认浏览器普通打开。

- 数据来自东方财富公开行情接口（push2.eastmoney.com），非 Level-2，约 8 秒级延迟的快照

- 接口为网页公开接口，仅供个人学习研究使用，请勿高频抓取
